Payments

Choose a single payment processor. Only the selected provider's fields are shown and offered at checkout. After saving, restart the server.

PayPal Fees

Obtain credentials from developer.paypal.com. After saving, restart the server.

Stripe Fees

Obtain API keys from the Stripe dashboard. After saving, restart the server. Leave the keys blank to disable Stripe at checkout.

Zelle (manual / offline)

Enable Zelle as a checkout option. Buyers send payment manually from their bank's Zelle app and enter the confirmation; orders stay pending until an admin verifies the transfer. Zelle works alongside (or instead of) a card processor. The Zelle email is required to enable it.

Multi-Factor Authentication (MFA)

Require members to verify their identity with a one-time code (email, SMS, or an authenticator app) when they register and/or sign in. Choose Disabled to turn MFA off for everyone — including administrators. Choose Admins only to exempt members from MFA while still requiring it for all administrators (admin, store, float, and finance).

SMS Gateway — Plivo (for text-message MFA)

Enter your Plivo credentials to send MFA codes by SMS via the Plivo Verify API. Leave these blank to disable SMS sending (email MFA still works). Get credentials from the Plivo console. Changes take effect after a server restart.

From the Plivo Verify product. Required to send sign-in codes via the Plivo Verify API (replaces the Messaging API).

Season

When this date arrives each year all member dues and fees are automatically reset to unpaid. The server checks at midnight UTC each day.

Approval Email (sent when a registration is approved)

Available placeholders: {{full_name}}, {{email}}, {{temp_password}}. Leave blank to use the built-in default message.

Denial Email (sent when a registration is denied)

Available placeholders: {{full_name}}, {{email}}. Leave blank to use the built-in default message. The account is deleted after this email is sent.

Changes take effect after a server restart.
